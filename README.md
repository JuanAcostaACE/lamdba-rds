# lambda-rds

Proyecto Lambda para integración con RDS.

## Descripción

Este repositorio contiene una función de AWS Lambda diseñada para interactuar con una base de datos RDS.

## Estructura

- `index.js` — punto de entrada de la función Lambda
- `package.json` — dependencias y configuración del proyecto
- `package-lock.json` — bloqueo de versiones de dependencias
- `.github/` — flujos de trabajo de CI/CD
